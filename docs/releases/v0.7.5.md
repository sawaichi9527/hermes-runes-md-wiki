# Hermes Runes MD Wiki v0.7.5

Status: final release
Release date: 2026-08-15

## Summary

v0.7.5 is a functional release that restores the Runes Shield runtime read-only tools and brings the OPC 8-profile governed wiki namespace into the formal mainline.

Two merged pull requests in this release:

- **PR #3** — Restore runtime validator+fixtures so `tools/runes_shield/` no longer depends on `dev/`.
- **PR #4** — Add OPC v4.1 `opc` namespace (8 roles) + Plur slot in source-priority (M5), ported from the K6 local mainline.

## Highlights

- Fixed `ModuleNotFoundError` in the P0 Runes Shield tools (`proposal_registry`, `proposal_review_queue`). Root cause was commit `e1cb587` moving `validate_proposal_fixture.py` and the proposal fixtures under `dev/` while the runtime CLIs still imported them from the same directory.
- `tools/runes_shield/` is now self-contained: validator + fixtures copied into the runtime with `DEPENDENCY_NOTES.md` documenting each `dev/` source for future maintenance.
- Smoke tool entries removed from `runes_shield_tools_index.json`; smoke scripts remain in `dev/` as developer-only assets.
- New `wiki/freelancer/opc/` namespace with 8 role READMEs for the OPC profile set.
- Plur slot added at source-priority #4 (Runes wins on conflict; engram flagged for manual prune).
